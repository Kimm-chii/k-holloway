# Holloway

Design concept for a walking trail. The hero is a scroll-driven 2.5D scene on one canvas: a meadow at golden hour, a lane into a tunnel of trees, then out to a pond.

- Plain HTML, one `index.html`, no build step and no libraries.
- Scroll walks you down the lane. "Start walking" or clicking the trees plays the whole walk.
- Reduced motion: no walking or swaying, the hero switches from meadow to pond.
- Open `index.html` in a browser to view. All trail details are placeholders.
